# BookReader — Реестр функций и план масштабного тестирования

Цель: проверить КАЖДУЮ функцию приложения минимум 2 способами, зафиксировать время и методы.
Формат отметки: `[ПРОВЕРЕНО] Время: <дата ЧЧ:ММ> | Способ1: <...> | Способ2: <...> | Результат: OK/BUG <описание>`

Легенда способов:
- S1 = браузерный E2E (hermes verify + http://localhost:8080, клики/навигация через browser-инструменты)
- S2 = unit/логическая проверка кода (чтение + вызов функции через node/тест, или проверка зависимостей/данных)
- S3 = проверка через импорт/экспорт данных (состояние store, JSON)
- S4 = проверка через консоль браузера (window-вызовы, DOM-инспекция)
