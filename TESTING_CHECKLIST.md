## 1. Імпорт книг (Library)

- [ ] **EPUB** — відкривається, текст читається, обкладинка (якщо є) показується
- [ ] **FB2** — відкривається, текст читається
- [ ] **TXT** — відкривається, текст читається
- [ ] **DOCX** — відкривається
- [ ] **ODT** — відкривається
- [ ] **RTF** — відкривається
- [ ] **HTML/HTM** — відкривається
- [ ] **MOBI/AZW/AZW3/PRC** — відкривається (Kindle-книги), текст читається
- [ ] **ZIP** — архів з книгою всередині (txt/fb2/epub/mobi/docx/odt/rtf/html) відкривається, текст читається
- [ ] **ZIP з EPUB всередині** — розпаковується і відкривається як epub
- [ ] **ZIP з TXT всередині** — розпаковується, текст читається
- [ ] **Непідтримуваний формат** (напр. `.pdf`, `.doc`) — показує «Unsupported format» + список підтримуваних, **не** пустий читач
- [ ] **Порожній/битий файл** — показує «Could not extract text», не краш
- [ ] **Повторний імпорт того ж файлу** — не створює дубль
- [ ] **Формат на картці книги** — видно `EPUB · EN → UK · N words`

## 2. Режими читання (Reader)

- [ ] **Read (оригінал)** — текст видно, без перекладу
- [ ] **Dual (паралельний переклад)** — оригінал + переклад під кожним реченням
- [ ] **Speed reading → RSVP** — слова по одному, швидкість регулюється
- [ ] **Speed reading → Ticker (бігуча стрічка)** — текст рухається, швидкість регулюється
- [ ] **Перемикання мови перекладу** — не втрачає попередні переклади (per-language у БД)
- [ ] **Скрол без «дьоргання»** — переклад підвантажується батчем, layout не стрибає
- [ ] **Тап по слову** → попап з перекладом + додаванням у словник (в усіх режимах)
- [ ] **Озвучка речення** (кнопка ▶) — працює (TTS)
- [ ] **Прогрес читання** — зберігається, відкриття вдруге → продовжує з того місця
- [ ] **Закладки** — додати/видалити/перейти

## 3. Переклад та ліміти (КРИТИЧНО для релізу)

- [ ] **Кнопка refresh у хедері** (обидва режими) → відкриває модалку «Translation services»
- [ ] **Модалка показує 5 провайдерів** + статус кожного (Available / resets in X)
- [ ] **Переклад працює через failover** — якщо Google вичерпано, автоматично перемикається на MyMemory/Libre
- [ ] **Ліміт НЕ вичерпується за кілька сторінок** (батчинг) — переклади декілька глав поспіль
- [ ] **При повному вичерпанні** — модалка з розкладом поновлення, кнопка «Try again»
