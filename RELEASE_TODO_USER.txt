================================================================
 ЧТО ТРЕБУЕТСЯ ОТ ТЕБЯ ДЛЯ ВЫПУСКА BOOKREADER
 (код и конфиги уже готовы — нужны только аккаунты/решения)
================================================================

--- 1. GOOGLE PLAY DEVELOPER ACCOUNT ---
  • Регистрация: play.google.com/console
  • Стоимость: разово $25 (проверь актуальную цену при оплате)
  • Без этого опубликовать нельзя.

--- 2. ADMOB (реклама) ---
  • Аккаунт: admob.com (тот же Google-логин, что и Play)
  • Создать App → скопировать AdMob App ID:
      ca-app-pub-XXXXXXXXXXXXXXXX~XXXXXXXXXX
  • Внутри приложения создать 2 Ad Unit:
      - Banner:  ca-app-pub-XXXXXXXXXXXXXXXX/XXXXXXXXXX
      - Rewarded: ca-app-pub-XXXXXXXXXXXXXXXX/XXXXXXXXXX
  • Заполнить налоговые/платёжные данные (иначе деньги не выплатят).
  • Привязать AdMob к Play Console.

--- 3. EXPO EAS ---
  • Установить CLI:  npm install -g eas-cli
  • Залогиниться:  eas login   (бесплатный аккаунт expo.dev)
  • Android-сборки в EAS БЕСПЛАТНЫ (платят только за iOS).

--- 4. ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ (URL) ---
  • Файл PRIVACY_POLICY.md уже лежит в проекте — замени email на свой.
  • Залей на публичный URL (например GitHub Pages).
  • Этот URL ОБЯЗАТЕЛЬНО вписать в Play Console.

--- 5. ИМЯ ПАКЕТА (package name) ---
  • Сейчас стоит: com.bookreader.app
  • Поменять ДО первой публикации (потом нельзя).
  • Задать через переменную EXPO_PUBLIC_ANDROID_PACKAGE при сборке.

--- 6. (ОПЦИОНАЛЬНО) ДОНАТ — ВНЕШНИЙ ЛИНК ---
  • Рекомендую Stripe/Polar вместо Google Play Billing
    (чтение бесплатно, это донат, не цифровой товар → нет среза 15%).
  • Линк вставляется в onDonate (ReaderScreen).

================================================================
 КОМАНДЫ ДЛЯ РЕЛИЗА (после получения ID из пп. 2 и 5)
================================================================

# Тест на телефоне (dev-сборка, hot-reload):
eas build --profile development --platform android
# ИЛИ просто потыкать (preview, прод-JS):
eas build --profile preview --platform android
# Ссылку на APK качаешь на телефон → разрешаешь установку → ставишь.

# Прод-сборка (.aab для Play):
export EXPO_PUBLIC_ADMOB_APP_ID=ca-app-pub-XXXX~YYYY
export EXPO_PUBLIC_ADMOB_BANNER_ID=ca-app-pub-XXXX/YYYY
export EXPO_PUBLIC_ADMOB_REWARDED_ID=ca-app-pub-XXXX/YYYY
eas build --profile production --platform android

# Выложить в Play:
eas submit --platform android

================================================================
 ЧТО ЗАПОЛНИТЬ В PLAY CONSOLE (обязательно)
================================================================
  • App signing: Play App Signing (Google хранит ключ).
  • Target API: Expo SDK54 ставит свежий; если Play ругается — обновить SDK.
  • Content rating: анкета.
  • Data safety: указать "Advertising ID" + "данные третьим лицам (ad network)".
  • Ads: отметить "приложение содержит рекламу".
  • Store listing: иконка (из assets/icon.png), скриншоты (телефон+планшет), описание.
  • Privacy policy: вставить URL из п. 4.
